# Front-End Developer Portfolio

A responsive, scalable portfolio landing page built with HTML, Tailwind CSS, and Flowbite.

## Run locally

Open [index.html](index.html) directly in your browser, or serve the folder with a simple static server if you prefer.

## Structure

- [index.html](index.html) — main portfolio content
- [src/style.css](src/style.css) — Tailwind entry and small custom styles
